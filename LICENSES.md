# Licences of models and data

Tiro's own code is MIT (see `LICENSE`). This file records every third-party **model** and **dataset** used to build,
train or test Tiro, with its licence and how it is used. It is checked against each source's own licence page.

"Ships" means the file is in an installer or offered as an in-app download. "Training" means it was used to
train or distil a model Tiro ships. "Test only" means it was used only to measure accuracy.

### Training data (used to distil and fine-tune the models Tiro ships)

| Dataset | Licence | Subset used |
|---|---|---|
| [LibriSpeech](https://www.openslr.org/12) train-clean-100/360, train-other-500 | CC-BY-4.0 | all 960 h |
| [VoxPopuli](https://github.com/facebookresearch/voxpopuli) English train | CC0-1.0 | every other file (about half) |
| [AMI Meeting Corpus](https://groups.inf.ed.ac.uk/ami/corpus/) IHM and SDM train | CC-BY-4.0 | all (train meetings only; dev/test meetings never used) |
| [People's Speech](https://huggingface.co/datasets/MLCommons/peoples_speech) `clean` subset | CC-BY-4.0 (the CC-BY-SA subsets are **not** used) | every 13th file |
| Synthetic sentences (`training/synth/sentences.py`) | generated by Tiro (MIT) | 120,000 dictation-style sentences; 15% of vocabulary terms held out |

Transcripts for training come from teacher models (below); the corpora's own transcripts are only used to filter
out clips where the teacher disagrees with the human transcript.

### Not used for training, on purpose

GigaSpeech and Common Voice need you to accept their terms on Hugging Face or Mozilla's site, so they are only used
through the public Open ASR leaderboard test copies. SPGISpeech is non-commercial (test only). TED-LIUM is
CC-BY-NC-ND (not used). Earnings-22 is CC-BY-SA-4.0 (test only).
